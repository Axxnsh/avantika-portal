## 🚀 वेबसाइट कैसे खोलें (How to Run / Open)

### तरीका 1: सीधा ब्राउज़र में खोलें (Direct File Open)
1. फ़ोल्डर खोलें: `C:\Users\Admin\.gemini\antigravity\scratch\ignou-clone`
2. `index.html` फ़ाइल पर डबल क्लिक (Double Click) करें।
3. आपकी पसंदीदा ब्राउज़र (Chrome, Edge, Firefox) में वेबसाइट तुरंत खुल जाएगी!

### तरीका 2: लोकल सर्ver चलाकर (Local HTTP Server)
अगर आप इसे लोकल सर्वर पर चलाना चाहते हैं:
```bash
cd C:\Users\Admin\.gemini\antigravity\scratch\ignou-clone
npx serve .
```
और ब्राउज़र में दिए गए लोकल लिंक को खोलें।
